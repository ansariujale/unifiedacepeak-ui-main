# Deliverables

Copies of the reviews, plans and sheets, gathered here so they can be opened and
shared without going through the repo tree.

**The markdown files are copies.** `docs/` is the source of truth for those — if
one is edited, edit it there. The CSVs exist only here; they were produced in a
session scratchpad that is not part of the repo.

The CSVs import directly into Google Sheets (File → Import → Upload).

| File | What it covers |
|---|---|
| `company-and-urls-update-plan.md` | The company settings and URL restructure, as tickets with acceptance criteria |
| `company-settings-review.md` | Section-by-section review of what company settings do today |
| `account-users-numbers-review.md` | The same for My Account, users and numbers |
| `queues-ivr-build-plan.md` | Call queues and IVR: what to improve, what to build, in what order |
| `genesys-cloud-reference.md` | Reference notes on the object model we compared against |
| `call-queues-and-ivr-sheet.md` | The queue and IVR feature comparison in table form |
| `MCM-company-three-way.csv` | Three-way feature comparison with a keep-or-change recommendation per row |
| `MCM-company-final.csv` | The consolidated company feature sheet |
| `MCM-company-status.csv` | What is built, what is partial, what is not started |
| `MCM-company-test-plan.csv` | Test cases for the testing team |
| `MCM-logic-to-change.csv` | Where our logic differs and should change |
| `MCM-what-to-build-next.csv` | Build order |
| `MCM-company-architecture.csv` | How the company record is actually stored |
